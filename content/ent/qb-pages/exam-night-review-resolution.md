### Q2 (p.2840) — a fourth management key for the same picture

Three printings of one scenario, and the bank does not agree with itself:

| | stem | keyed |
|---|---|---|
| `entep-throat-6` | 30yo teacher, HOV **4 months**, inflamed oedematous VCs, no organic mass | **Medical treatment and follow-up** |
| `entep-throat-28` | 37yo teacher, HOV **4 months**, inflamed oedematous VCs, no MAP lesions | **Medical treatment and follow-up** |
| **Q2, p.2840** | 30yo teacher, HOV **3 weeks**, inflamed oedematous VCs, no organic mass | **Antireflux medications and voice therapy** |

The **option set is replaced** — generic "medical treatment" becomes "antireflux
medications" in all four options — so by the mechanism rule this is a new entry,
not a re-key of an existing one. But the clash is real and must be recorded in
both directions: `entep-throat-28`'s key was **re-affirmed by the bank's own
errata section at p.2823** with a newly written box, so "medical treatment and
follow-up" is its settled position, and p.2840 keys something else for a
near-identical vignette. **The duration does not explain it** — 3 weeks is
*shorter* than 4 months, and if anything a longer history argues for more
intervention, not less.

### Q13 (p.2862) — the option set is what moved the key

| | question | options | keyed |
|---|---|---|---|
| `entep-nose-56` | 3yo, optimum **imaging** modality | US / X-ray / MRI / angiography | **Plain X-ray** |
| **Q13, p.2862** | 4yo, optimum **modality** (no "imaging") | **flexible nasopharyngoscopy** / frontal PNS X-ray / EUA / CT | **Flexible nasopharyngoscopy** |

**Both keys are internally correct and this is NOT a contradiction.** Dropping
the word "imaging" is what lets a non-imaging test win, and the bank supplied it.
Worth noting because it is the opposite of the self-contradictions elsewhere in
this file: here a changed option set changed the answer *legitimately*.

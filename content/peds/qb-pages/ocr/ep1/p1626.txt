72. Which of the following is FALSE as regards meconium ileus?
a. Microcolon is noted on barium enema
b. Double-barreled ileostomy can be done in these cases
c. Sweat chloride test is among the workup for this disease
d. Operative option is indicated in all cases
Not all cases require surgery; some can be managed non-surgically with
contrast enemas. Microcolon is typical, double-barreled ileostomy is a
surgical option if needed, and sweat chloride test helps confirm cystic
fibrosis.
